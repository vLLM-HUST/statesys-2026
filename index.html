Why StateSys

State has become the critical systems resource.

Many services now depend on shared or long-lived state for performance, efficiency, and service quality. StateSys 2026 brings together work on how systems organize, access, schedule, evolve, migrate, and reuse state across cloud runtimes, data systems, storage stacks, serverless platforms, stream processing, graph systems, and model serving.

Topics

Topics of interest include the following areas.

State Access and Sharing

Access paths, shared state, locality, observability, concurrency, and cross-node access.

State Placement and Scheduling

Partitioning, placement, caching, tiering, and state-aware task and resource scheduling.

State Consistency and Coordination

Consistency models, synchronization, concurrency control, replication, and distributed coordination.

State Migration and Recovery

Migration, checkpointing, fault tolerance, elasticity, and online reconfiguration.

State Evolution and Reuse

Online updates, versioning, lifecycle management, and reuse across requests or tasks.

Stateful Systems and Applications

Data and storage systems, stream and graph processing, serverless platforms, and model serving.

Call for Papers

Original research, system experience, position papers, and work in progress.

The call for papers covered state management in systems software and infrastructure. Topics included production systems, experimental prototypes, measurement studies, benchmarks, or position papers that clarify open problems.

Accepted submissions are for presentation and discussion only. No proceedings will be published, and submissions will not appear in the ACM Digital Library.
